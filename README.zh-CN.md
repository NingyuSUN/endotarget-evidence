## 项目回答什么问题

限定为作者判定的增殖期、在位子宫内膜基质细胞，以每位供者作为一个统计观察，调整年龄、既定批次和腺肌症后，比较三种优先排序：

- B0：按表达差异证据强弱。
- B1：按网络加权连接数。
- G1：沿关联网络传播表达证据。

三种方法共同使用11,749个基因和123,313条边。网络传播与表达排序的前20名没有重合，与纯连接度排序重合9个；它是否提高外部复核价值仍未知。网络关联和优先级不能直接解释为药物作用或激活／抑制方向。
