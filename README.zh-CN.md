## 一句话研究问题

在子宫内膜异位症患者的**在位子宫内膜基质细胞**中，哪些表达变化能在另一项研究中重复出现？结合公开遗传证据，哪些基因值得继续研究，哪些应降低优先级？

“在位”指子宫内正常所在位置。首版对比相同组织部位的病例和非内异症对照，避免把组织位置差别直接解释成疾病差别。

## 为什么选择它

它与已有女性生殖、转录组、单细胞和遗传研究形成方法与生物问题上的延续。相比单纯换一个疾病训练分类器，这个设计要求你说明候选如何产生、独立证据是否支持、为何暂时不能推导治疗效果。

目前已核实存在公开发现队列和独立研究的候选复核资源。最终合格供体数量、周期可比性、原始计数层与计算成本仍需在第一阶段确认。

## 首版做五件事

1. **核对数据。** 明确供体、组织、周期、激素治疗、批次与来源；统计独立患者数。
2. **寻找可解释的变化。** 把同一供体同一细胞谱系的计数汇总，比较病例与对照，同时检查周期和细胞状态构成。
3. **比较三个排序方法。** 差异表达、网络连接数、图网络传播；图方法不预定获胜。
4. **独立复核并补充遗传证据。** 先冻结名单再查看外部效应；遗传支持与表达复现分栏展示。
5. **交付研究档案。** 为最多5个候选写支持证据、反证、作用方向是否明确和后续公开证据需求，附可复现流程与生物学报告。

“很多细胞”不等于“很多独立患者”；“表达上调”也不等于“抑制这个基因会治病”。这是需要能够独立解释的两个核心判断。
