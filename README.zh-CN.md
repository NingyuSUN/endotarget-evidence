# EndoTarget Evidence：子宫内膜异位症候选靶点证据研究

**两个公开队列的真实计数和供者设计已验收；尚未计算疾病效应或候选靶点排名。**

项目位于 `SRV01:/home/analyst/te`。下载、代码、环境、测试和分析都在服务器项目内；已有本地 Git 仓库，尚未发布到 GitHub。

当前状态 · [实际输入与来源](docs/INPUT_PROVENANCE.md) · [研究协议](docs/RESEARCH_PROTOCOL.md)

## 要回答的问题

在子宫内膜异位症患者的**在位子宫内膜基质成纤维细胞**中，哪些表达变化能在另一项研究中重复出现？结合独立遗传证据，哪些基因值得进一步研究，哪些证据不足或相互冲突？

“在位”指子宫内膜正常所在的位置。两个队列都使用作者最终判定的增殖期，保留激素与组织学信息的限制。来源对照可能有其他妇科疾病，不能一概称为健康人。

## 已经做出的真实数据成果

| 队列 | 独立供者 | 纳入细胞／细胞核 | 可用稳定基因 |
|---|---:|---:|---:|

| 外部 HECA 新生成核数据，E-MTAB-14039 | 22：15病例、7对照 | 52,744细胞核，全部匹配原始矩阵 | 26,125 |

发现队列保留原始定量方法产生的分数计数，没有强行取整；外部队列采用22个公开的真实整数计数文件，共下载1.582 GB。两者共有21,585个可对应基因编号，尚未经过表达过滤，也不是最终网络比较范围。

临床表、计数列与设计矩阵已经逐供者对齐。两个主要模型都可以在数学上估计疾病项；这不能保证样本量充分或混杂已消除。严格排除组织学阶段冲突后，HECA仅剩3名对照，低于预定最低5名，因此该敏感性分析不能估计，不能降低门槛补救。

固定的23个标志基因用于整体合理性检查；不读取疾病分组、不修改纳入条件。结果不能给出细胞纯度，也不能证明所有宫颈或其他成分都已逐细胞排除。两个队列来自不同招募研究，但没有跨研究基因型身份核验。

网络参考已固定：159,312条基因关联、14,554个节点，仅保留直接实验或数据库通道。它还不是靶点排名，关联也不等于直接结合或因果调控。

## 问题与处理

HECA的H5表达层已经标准化并取对数，不能直接作为原始计数输入。项目改用同研究公开的未标准化矩阵，没有反变换或强行四舍五入。

原始矩阵比作者保存的H5总量多9,607个UMI，占360,765,431个原始UMI的0.00266%。基因过滤能解释一部分，完整原因尚未证明；原始计数和细胞均未为此修改。这一限制与发现队列的次级汇总来源、基因版本差异一起保留在报告中。

63项集成软件测试通过，但它们验证的是程序边界和文件接口，不是疾病机制、独立科学复现或药效。完整原始发现RDS没有重新导入；容器和AWS都没有实际运行。

## 后续研究顺序

1. 固定统计软件与表达过滤规则，完成可执行流程。
2. 在发现队列中比较表达排序、连接度排序、网络传播三个基线。
3. 冻结名单、方向和评价规则，再计算外部疾病效应。
4. 报告缺失、方向一致性、稳定性、失败结果和独立遗传证据。
5. 形成可复查的候选／反例档案、生物学报告、Nextflow流程和实际容器运行记录。

图方法不预定获胜；没有可靠候选也应如实交付。首版是图网络传播基线，不声称训练了GNN或基础模型。全部使用公开数据，不新增湿实验。
