# Fixed discovery ranking implementation

Status: implemented and tested on synthetic data only; no real disease ranks generated by this implementation round. Software tests are not scientific/external validation. No final external freeze is asserted.

## Interface

Execute from `/home/analyst/te`, after the root-owned method/discovery readiness authorization:

```bash
envs/m0-h5/bin/python scripts/rank_targets.py \
  --de PATH_TO_DISCOVERY_DE_FITTED.tsv \
  --de-all PATH_TO_DISCOVERY_DE_ALL.tsv \
  --edges data/reference/string/direct_evidence_gene_edges.tsv.gz \
  --output-dir NEW_OUTPUT_DIRECTORY
```

The default config is `config/ranking_algorithm.json`; an optional `--config` path must contain exactly the same frozen algorithm. Production requires both `--de` and `--de-all`. No ranking parameter search or external effect/availability input exists. `--synthetic-test` allows an unpinned synthetic edge file, retains the production >=50-gene threshold, and explicitly marks its provenance `SYNTHETIC_TEST_ONLY_NOT_A_SCIENTIFIC_FREEZE`. In synthetic mode only, omitting `--de-all` uses the same finite `--de` table as the complete family. Never use that mode for real research ranks. Tests use project-contained temporary files under `work/`, removed at test completion.

Discovery TSV or gzip TSV must contain unique unversioned `ENSG` IDs and finite fitted values in `gene_id`, `logFC`, `t`, `P.Value`, `adj.P.Val`, `AveExpr`. P and adjusted P must lie in [0,1]. Extra named DE columns are allowed but do not enter ranking. Duplicate headers, ragged rows, duplicate gene IDs, missing or nonfinite fitted values fail. The exact `--de-all` rows define discovery-expression membership, including rows with failed fitted fields; there is no further P-value/expression/significance cutoff and no external intersection. The DE producer owns its declared count-based expression filter and complete tested family; ranking cannot establish that arbitrary finite input t values are actually limma-moderated statistics. `--de-all` requires the six named fields and valid unique IDs but permits failed fitted values such as NA. Construct U from all its IDs first, then require every U gene to occur with finite fields in `--de`; a missing/invalid U fit fails rather than shrinking U. Failed fits outside U are allowed and reported as graph exclusions. Fitted genes outside the complete expression-pass family also fail. Root owns proving that `--de-all` is genuinely the complete producer family; the script cannot infer source-omitted rows.

The reference TSV/gzip TSV must have exactly `gene1`, `gene2`, `weight`. Production pins compressed-file SHA256 `84a4313292da6d6d69b76a4f721893aa89775beebeed9eabcb263fe93e797033`. Every edge, including those outside the induced graph, is schema/ID/weight checked. Weights must be finite within [0.7,1]. Upstream max collapse and self-loop exclusion are immutable: duplicate undirected edges and self loops are rejected rather than silently reprocessed. Accepted weights are retained without changing their meaning. The network is STRING 12.5 human direct experiments/database functional association, not physical binding or causal regulation. Original source/mapping provenance remains in the existing network reference and gene-mapping config/receipts.

## Common universe and methods

Take all discovery expression-pass IDs from `--de-all`, retain reference edges with both endpoints in this set, then remove genes with zero degree in that induced graph. A gene connected only to a gene outside discovery is excluded. Record all exclusions with denominator. Final U must contain >=50 genes. Disconnected nonisolated components remain valid. Every method uses precisely this U and its induced graph.

- B0: descending absolute discovery moderated t statistic.
- B1: descending weighted degree (sum of unchanged incident edge weights).
- G1: nonnegative symmetric adjacency, column normalized by source-node degree. Seed is abs(t) normalized to sum 1 on U; scale by max first to avoid overflow for extreme finite values. Iterate `p_next = 0.5*s + 0.5*W*p`, starting at `p=s`, until L1 change <1e-10, with at most 10,000 iterations. All-zero seeds and nonconvergence fail.

Sparse multiplication uses two NumPy `bincount` scatter sums over undirected edges; memory is O(nodes + edges), with no nodes-squared adjacency. All scores use float64. Probability mass/nonnegativity is checked at each propagation iteration; final L1 change, fixed-point residual, mass and maximum mass error are reported. These are numerical implementation checks, not calibrated biological probabilities.

Scores sort descending; exact numerical ties sort by stable gene ID. No approximate tie rounding is introduced. All methods preserve discovery logFC, t and the independently derived sign of logFC (`-1`, `0`, `+1`). In particular, zero logFC stays zero, regardless of unsigned score. Direction describes expression association, not activation/inhibition or an intervention recommendation.

## Outputs and preservation

`B0.tsv`, `B1.tsv`, `G1.tsv` contain complete ranked U; each has matching `_top20.tsv` and `_top50.tsv` prefixes. Columns: rank, gene_id, method, score, logFC, discovery_sign, t, P.Value, adj.P.Val, AveExpr, weighted_degree. Lists never refill using an external availability result.

`universe.tsv` is the sorted stable-ID set; `excluded_genes.tsv` reports induced zero-degree exclusions; `induced_edges.tsv` saves sorted canonical endpoints and float64 round-trip weights. `provenance.json` records input/config/code hashes, output hashes/bytes, exact algorithm, Python/NumPy versions, execution timestamp, counts, universe/induced-graph hashes and propagation diagnostics. The original complete `de_all` and finite `de_fitted` remain separate. Both file hashes are saved, preserving the full tested family and graph exclusions; no fit failure is treated as an unsigned zero seed.

Existing output or `.partial` directories are preserved and cause failure. Write into a new `.partial` directory, then rename only after all tables/provenance have been written. A disk/write failure can leave an inspectable partial; no previous freeze is overwritten. Inputs are rehashed after ranking before output creation. The output provenance deliberately states `complete_external_freeze=false`; the root integration owns complete software/design/donor/list/evaluation freeze, external analysis authorization, and atomic freeze orchestration.

## Tests and limits

```bash
envs/m0-h5/bin/python -m unittest discover -s tests -p test_rank_targets.py -v
envs/m0-h5/bin/python -m unittest discover -s tests -v
```

Hand-solvable tests cover the two-node 2/3 versus 1/3 stationary solution, weighted three-node column normalization, induced isolation, weighted degree, identical universes, deterministic exact ties, independent expression signs, disconnected nonisolated components, finite extreme seeds, >=50 after isolation, zero seeds, nonconvergence, malformed/duplicate/nonfinite inputs, strict immutable graph validation, missing U fits versus failed fits outside U, duplicate/invalid complete eligibility, CLI outputs/hashes/list prefixes, synthetic labeling, and overwrite/pin failures. Tiny hand calculations use the explicitly named Python-only `test_min_universe` override; the CLI exposes no threshold override. CLI integration uses 60 wholly synthetic genes, checks a missing 61st network-eligible fitted gene fails without output, verifies production rejects missing `--de-all`, and cannot supply an external input.

Limitations: retrospective source-informed design; discovery DE must already satisfy modeling/count/donor contracts; reference mapping has documented name-based limits; network unsigned priorities may favor connectivity; fixed parameters are not optimized; exact floating-point ties can depend on machine/library arithmetic at tiny precision differences. No real cohort inference, final freeze, external replication, therapeutic validity, Docker run or AWS execution is established by these tests.

No routine user decision is needed within this implementation scope.
