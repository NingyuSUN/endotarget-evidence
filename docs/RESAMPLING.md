# Prespecified donor resampling

These new modules preserve the frozen primary scripts/configurations. Run from `/home/analyst/te` after sourcing `scripts/statistical_runtime_env.sh`. Synthetic software success is not biological replication. Actual public-data resampling must follow the integrated external-effect/evaluation stage; do not create substitute lists or masks.

## External bootstrap

```bash
source scripts/statistical_runtime_env.sh
Rscript scripts/resample_donor_models.R --mode bootstrap \
  --primary-model work/statistical/heca_primary/de/model.rds \
  --eval-mask work/statistical/heca_primary/evaluation/bootstrap_interface.tsv \
  --output-dir work/statistical/bootstrap --workers 4
```

Defaults use frozen HECA counts/clinical/config and both existing freezes. The evaluator interface has 210 long rows (three methods times top20/top50): method,k,rank,gene_id,discovery_sign,original_evaluable; extra evaluator columns are retained by that module. Bootstrap verifies these exact lists/signs against the discovery freeze and recomputes the original evaluability check from the original HECA primary model before any resampling. The model output hashes must match primary provenance, whose input hashes must match current frozen source files.

R Mersenne-Twister/Inversion/Rejection with seed42 generates exactly500 draws, stratifying15ENDO and7non-ENDO with replacement. Write the complete11000-row donor draw ledger, input/code/runtime hashes, fixed family and binding RDS before any fits. Original HECA gene family and top20/top50 evaluability remain fixed. Recompute retained-library sums,TMM,voom and all-family robust eBayes with identical frozen parameters; do not refilter. BH includes the full fixed family including failed genes. Duplicate people are deliberate bootstrap multiplicities, not new biological donors; record actual unique people per group and nominal model degrees of freedom, never enforce5unique people in a draw.

Age is recentered and sorted observed batch levels supply fresh treatment contrasts. Only constant nuisance covariates are dropped and listed. Nonconstant collinearity, no mixed disease batch, or nominal residual df<5 invalidates a draw. Any original-evaluable gene in the union of top20/top50 that lacks a valid finite refit or has exact-zero effect invalidates the paired draw. Originally unevaluable genes never enter denominators. No invalid draw is replaced. The paired G1-minus-B0 top20 rate uses the same draw and each method original fixed evaluable denominator. Report500outcomes and failure reasons; >50failures suppresses intervals, otherwise compute2.5/97.5percentiles with R quantile type7 on valid differences and disclose valid-only conditioning if needed. This is conditional external sampling sensitivity, not complete pipeline uncertainty or500independent cohorts.

`--workers` accepts1(default)through4. The complete ledger is generated by the parent before bounded Unix worker forks; `mc.set.seed=FALSE` because fitting consumes no random draws. Source the runtime before launching so each worker has BLAS/OMP threads1. Per-draw files have atomic SHA256 sidecars; recovery checks the checksum,fixed agree/evaluable/selected counts,rates and finite paired difference before reuse. Per-draw files contain worker PID,elapsed time,unique people,design receipt and fixed-denominator results. `process.json` records parent PID/host/workers and completion exit status. A scientifically invalid draw is not a failed OS process. Final input/code hashes are rechecked before summary. No effect-driven estimator or subset choice occurs.

## Discovery leave-one-donor-out

```bash
source scripts/statistical_runtime_env.sh
python scripts/run_discovery_lodo.py --output-dir work/statistical/discovery_lodo
```

All22accepted discovery people define fixed folds. After removing each person,reapply>=8per disease and>=50cells, rebuild clinical design with the same limited constant-term policy, and call the unchanged frozen `fit_donor_model` with expression filtering redone using remaining group sizes. Feed complete expression-pass DE and fitted DE separately into unchanged `rank_targets.execute`; pass the frozen full STRING reference. Each fold reconstructs its induced graph,zero-degree exclusions,weighted degrees,seeds,B0/B1/G1 and full/top20/top50rankings. No external effects are consulted. Compare each top20 to frozen full-discovery top20: retention=intersection/20; Jaccard=intersection/union. Disappearing reference genes are losses. All failed folds stay not estimable and are never replaced. `fold_metrics.tsv` lists every donor/method,outcome and error; `summary.json` reports valid-fold denominator. Folds run serially with BLAS/OMP threads1 and record childPID/exitstatus.

## Checkpoints and failure handling

Repeat the exact command/output directory to resume. Bootstrap binds counts,clinical,config,primarymodel,mask,freezes,runtime lock,sourcecode,family and draw ledger. LODO binds those applicable inputs plus full-discovery reference lists,network and rankercode. Changed input/code/runtime hashes reject reuse. Completed draw/fold files are reused without refits. A bootstrap JSON lacking its final checksum is uncommitted and must be preserved/inspected rather than silently trusted. LODO also verifies all checkpoint output hashes. A process interruption before an atomic fold checkpoint leaves its partial directory preserved and requires inspection/moving that partial to an archive before continuing that exact donor; completed failed folds never get a replacement. Source/output files and logs are ignored by Git; only new modules,tests,documentation and small test receipt are committed.
