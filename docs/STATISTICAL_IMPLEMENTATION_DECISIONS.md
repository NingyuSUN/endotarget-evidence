# Statistical implementation decisions — pre-effect contract

Date: 2026-10-13. Status: **ADOPTED BEFORE DISEASE EFFECTS**, within the authorized v1 protocol. This document resolves implementation choices, not a preregistration or scientific validation. Base inspected: 9252a54; M0 permits implementation with its existing source limits. No cohort disease model, ranking or external disease outcome was calculated for this contract. Machine parameters: config/statistical_analysis.json.

## 1. Statistical unit, inputs and fixed target

One selected donor pseudobulk is one observation. Use the accepted stable-gene count matrices and exact clinical/design order; reject duplicate IDs, malformed/negative/nonfinite counts, donor permutations and changed hashes. Discovery fractions are retained as doubles without rounding, inversion, rescaling to integers or pretending they are original observed UMIs. The accepted secondary Alevin aggregation is estimated count mass; inference does not propagate quantification/assignment uncertainty or reconstruct the full source RDS. HECA requires original nonnegative integer counts.

The primary estimand is the adjusted ENDO-minus-non-ENDO difference in normalized log2 stromal pseudobulk expression. It is an association across these selected donor groups. It is neither a cell-specific causal effect nor a cell-state composition adjustment; adenomyosis may also reflect shared disease processes, so adjustment does not identify a total causal disease effect.

Primary matrices are authoritative:
- discovery: reports/final_clinical_design_discovery_primary.tsv; intercept + ENDO indicator + mean-centered age in years + capture-batch indicators + adenomyosis; rank 12, residual df 10.
- HECA: reports/final_clinical_design_heca_primary.tsv; same structure with author literal library_group_Lane; rank 10, residual df 12.

The disease column is ENDO_minus_non_ENDO (non-ENDO=0, ENDO=1). Batch references are already frozen in these numeric matrices. Do not add nested discovery sequencing batch, library/donor dummy variables, cell counts as independent observations, surrogate variables, interaction terms or effect-driven covariates. Full rank, residual df >=5, finite values, donor minima and mixed disease/batch support are checked before fitting. Record design singular values/conditioning as diagnostics without inventing an effect-driven rescue cutoff.

## 2. Expression filtering before normalization

Use edgeR::filterByExpr on the raw accepted-gene matrix with group=disease, design=NULL, lib.size=colSums(counts), min.count=10, min.total.count=15, large.n=10, min.prop=0.7. Explicitly pass disease groups so a DGEList default cannot silently treat all donors as one group.

The CPM threshold is 10 / median(raw accepted-gene library totals) * 1e6. At primary n, expression must pass that threshold in at least 10 discovery donors or 7 HECA donors anywhere in the cohort, and total count mass must be >=15. These are not requirements to pass in each disease group. The use of group affects only the smallest group size: permuting group labels while keeping group counts fixed cannot change retained genes. Consequently external filtering is effect-blind and independent of label allocation conditional on known group sizes; it is not independent of the metadata sample-size decision.

Do not pass the full covariate-rich design to filterByExpr: leverage from many batch terms can make its effective support requirement very small. The selected group-size rule deliberately demands broader expression support. Low counts can nevertheless remain noisy, and inherited mapping exclusions cannot be recovered.

Record every retained/rejected stable ID, raw-library totals, cutoff, effective support count, and the installed function version. Discovery alone supplies eligibility. HECA filtering never intersects or edits discovery U or top lists. [Official edgeR reference manual](https://bioconductor.org/packages/release/bioc/manuals/edgeR/man/edgeR.pdf) documents the filter parameters; the choice to use group-size support is this project's pre-effect ruling.

## 3. Normalization and model mechanics

After filtering, subset with keep.lib.sizes=FALSE (or equivalently construct a fresh DGEList from the retained matrix). Recalculate per-donor totals. Run TMM using method="TMM", refColumn=NULL, logratioTrim=0.3, sumTrim=0.05, doWeighting=TRUE, Acutoff=-1e10, p=0.75. The installed edgeR automatic reference choice is pinned by its version and recorded; no reference donor is chosen for a favorable effect. TMM changes effective library sizes, not the source count matrix. Its composition adjustment assumes sufficient usable reference expression and cannot identify a uniform absolute RNA increase across all genes.

Run limma::voom with this DGEList and the full numeric design, normalize.method="none", span=0.5, adaptive.span=FALSE where available, no block/correlation/prior weights, plot=FALSE, save.plot=TRUE. Then lmFit(method="ls") and eBayes(proportion=0.01, stdev.coef.lim=c(0.1,4), trend=FALSE, robust=TRUE, winsor.tail.p=c(0.05,0.1), legacy=TRUE where supported). No sample-quality weights, quantile normalization, duplicateCorrelation, fold-change threshold tests or automatic estimator changes are introduced.

The fixed span prevents newer defaults from changing smoothing. Legacy robust moderation fixes the established Winsor-based algorithm; choosing it is reproducibility policy rather than proof it is optimal. Voom already models abundance-dependent precision, so no second eBayes abundance trend is added. [Official limma reference manual](https://bioconductor.org/packages/release/bioc/manuals/limma/man/limma.pdf) documents voom accepting estimated counts with meaningful library sums and the adaptive.span/legacy options. This does not validate this secondary source's biological accuracy. The [official workflow](https://bioconductor.org/packages/release/workflows/vignettes/RNAseq123/inst/doc/limmaWorkflow.html) gives the standard filter, recalculate totals, normalize and voom sequence.

The solver reports a proposed R4.4.3/edgeR4.4.0/limma3.62.1/statmod1.5.2 runtime; actual installed versions and function formals MUST be captured before effects. A missing adaptive.span argument is compatible only when installed voom uses the requested fixed span. A missing legacy argument is compatible only with the pre-legacy robust algorithm. Record this explicitly, never catch arbitrary parameter errors and retry with defaults. Any other unsupported requested option fails. Archive effective parameters and sessionInfo in the run receipt; web-current manuals are guidance, not the executed software lock.

Return coefficient, moderated t, SE=sqrt(s2.post)*stdev.unscaled, df.total, two-sided p, BH q and 95% moderated t interval. Intervals describe model uncertainty conditional on this analysis; they do not cover source errors, selection or causal confounding. No numerical sign epsilon: positive, negative and exact zero remain distinct. Warnings/nonfinite results are retained with reasons; do not impute them to zero.

## 4. Gene family, universe and external evaluability

Each cohort's complete expression-pass family is its testing family, including genes outside STRING and outside discovery U. Apply BH to finite valid p values with n equal to the full expression-pass family size; failed-fit genes retain NA q and still count in n. Do not adjust only selected genes or the cross-study intersection. A failed whole-cohort design/model is a failed analysis. If a discovery U member lacks finite coefficient/t/p, the ranking gate fails rather than shrinking U around a fit problem.

Construct discovery U from discovery-expressed genes and the frozen permitted gene graph, then remove induced-degree-zero nodes. Save weighted degree, every discovery coefficient/sign, t, all three ranks, top20/top50 and the graph/config/software/input hashes before external disease effects. Directions for B1 and G1 are still the discovery coefficient sign, never the unsigned network score.

A selected gene is externally direction-evaluable only if it is present, passes the external count filter, has valid finite external coefficient/t/p, and has nonzero saved discovery and external coefficient signs. Record mutually exclusive missing-reason categories: absent ID, expression filter fail, invalid fit, discovery zero sign, external zero sign. Exact zero is not an opposite direction; tiny nonzero effects remain eligible but require effect-size interpretation. Significant directional support additionally requires external q<0.05 and agreement.

Report agree/evaluable/selected without replacing genes. Missing bounds are agree/20 and (agree+unevaluable)/20; G1-minus-B0 bounds subtract opposite endpoints. No superiority claim with <16 evaluable in either primary list or when the contrast bounds include zero. Even favorable bounds and a bootstrap interval establish transcriptomic comparison only. The primary rate uses each method's fixed evaluable denominator; report both denominators, not only their difference.

## 5. External bootstrap and discovery leave-one-out

Bootstrap: set R RNGkind("Mersenne-Twister","Inversion","Rejection"), set.seed(42); generate exactly 500 stratified resamples of 15 ENDO and 7 non-ENDO donors with replacement, storing the complete draw ledger before fitting. Use identical draws for B0/B1/G1. Keep original external retained genes, discovery lists/signs and original external evaluability masks fixed. Recompute retained-library totals, TMM, voom weights and all-gene empirical Bayes fit for each draw. Do not refilter or reduce the BH family. Resampling can yield a zero-library column only if an original retained column was already zero: that is a validation failure.

Rebuild the same covariate model in each draw: recenter age, drop absent batch levels and rebuild treatment contrasts using sorted observed levels. A now-constant nuisance term may be removed with an explicit receipt because it adds no contrast within that sample. No nonconstant nuisance term may be selectively dropped to repair collinearity. Require full rank, disease estimability, mixed batch support and nominal residual df>=5. A bootstrap sample is a resample of the original accepted cohort, not a new clinical cohort: original eligibility/minimum unique donor criteria are not reapplied to repeated draws. Record unique donors overall/per disease and nominal df; duplicated rows do not create new people or external information.

For joint primary and secondary list reporting, a failed design/model or any originally evaluable gene in the union of frozen top20/top50 lists having an invalid refit or zero refit sign invalidates that paired resample. Originally unevaluable genes do not become newly evaluable. Do not redraw failures. Report failure count/reasons; if >50/500 invalid, suppress interval claims. Otherwise use 2.5/97.5 percentiles (R quantile type 7) of valid paired G1-minus-B0 top20 concordance differences. Also disclose valid-only conditioning when failures occur. This is conditional external sampling sensitivity, not full pipeline uncertainty or a test based on 500 independent studies.

LODO: remove each discovery donor once, recheck original >=8/group and >=50-cell rules, rebuild the same covariates as above, refilter using remaining group sizes, recalculate TMM and refit voom/eBayes. Rebuild the fold's discovery-induced U, degrees, seeds and all rankings with frozen network parameters. This captures eligibility/graph changes rather than keeping the full-data universe secretly fixed. Compare top20 against the full-discovery reference using intersection/20 retention and intersection/union Jaccard; disappearing reference genes are losses, not omitted denominators. Failed folds are not estimable and never replaced; list all 22 outcomes and valid-fold denominator. No external effects enter LODO.

## 6. Matched null sets, fixed before external outcomes

For each method's primary top20 generate 200 sets of 20 from discovery U, excluding that method's own selected top20. Other methods' genes remain eligible. Keep expression and network degree as matching covariates only, with no disease sign/t/p, genetic evidence or external availability used to form bins or select the pool.

Expression is rowMeans(edgeR::cpm(discovery_normalized_DGEList, log=TRUE, prior.count=0.5, normalized.lib.sizes=TRUE)); degree is weighted degree in frozen U. Compute each variable's pooled-U quintile boundaries using type-7 quantiles, collapse duplicate internal boundaries, and put values equal to an internal boundary into the lower interval. Equivalent bin: 1 + count(value > unique_internal_quantile_cutpoints). Crossing expression and degree produces at most 25 bins. Do not separate identical values by gene-ID rank to manufacture balanced bins. Archive every U gene's covariates, bins, boundaries and every set membership before external disease effects.

Within each selected method, match its exact top20 bin occupancy, sample uniformly without replacement in each bin from stable-ID-sorted candidates; reuse across sets is permitted. Use numpy.random.Generator(numpy.random.PCG64(42)), initialize separately for each method in fixed order B0,B1,G1, and traverse bin tuples lexicographically. Distinct method streams can be correlated; these are not independent replicates. If any bin lacks the needed number of nonselected candidates, mark that entire method's null experiment NOT_ESTIMABLE. No bin merging, tolerance expansion, replacement sampling or effect-based retry. Each sampled gene carries its OWN frozen discovery direction.

Evaluate sampled sets after freeze with the same missingness rules and show coverage/missing bounds as well as concordance. Report distributions and observed descriptive percentile among coverage-adequate sets, explicitly counting total/adequate/inadequate sets. Do not claim a permutation p value or calibrated null of no disease effect: gene dependence, shared donors, repeated genes, coarse matching and disease-informed discovery signs prevent that interpretation. If no coverage-adequate sets exist, report not evaluable, not a rescue. These sets assess sensitivity to expression/degree structure, not a causal negative-control ground truth.

## 7. Identifiability, leakage and failure rulings

- Many batch terms reduce residual information. Full rank is necessary and cannot prove good precision, remove batch/clinical confounding, or validate a model from a p-value count.
- External detectability must not replace discovery-only eligibility. External disease results remain inaccessible until full ranking AND null-set membership freezes are hashed.
- Shared annotation/phase methods can induce shared errors. This is source-separated replication with scRNA/snRNA differences, not independent annotation truth or an independent clinical trial.
- Conditioning on author expression-assisted phase can influence ascertainment. No fresh expression relabeling or best-subtype selection is permitted.
- Pooled normalized expression used for null matching contains cohort signal but no disease-label contrast; matching never consults t/direction. Discovery signs are used only afterward to define the locked prediction for each random gene.
- Bootstrap and LODO answer different uncertainty questions. Failure is a recorded outcome, not permission to remove covariates, refilter externally or rerank discovery after seeing replication.
- Primary/30/100 cell thresholds, strict phase, adenomyosis-free and age-unadjusted sensitivities keep their prespecified meanings. Recheck eligibility/rank for each real subset. Already failed strict HECA and strict+adenomyosis-free discovery stay failed. A protocol revision is required before broadening phase, lowering minima, changing lineage or choosing models by effects.
- If a runtime limitation requires a materially different estimator or bin rescue, stop that stage and issue a dated ruling; do not silently replace this contract. Routine version capture and equivalent coefficient coding need no new user approval.

## 8. Acceptance checks before effects

Check on synthetic fixtures only: low-support genes remain excluded despite high-leverage batches; filtering is invariant to disease-label permutations at fixed group counts; fractions survive input unchanged; donor swaps/invalid counts/rank deficiency fail; coefficient direction flips when disease coding flips in a controlled positive example; every cohort family member counts in BH; no external outcome changes U/list/null sampling; resampling keeps paired masks and logs invalidity; bin ties and insufficient pools obey exact rules. Capture actual package versions, effective options, locked designs, config/input hashes and runtime receipts. Synthetic success establishes implementation behavior, not biological replication.
